# Fountain Play

**Fountain Play** is a demonstration program that renders a 3D fountain scene using C++ and OpenGL. It showcases how to load 3D models, apply textures and simulate water effects in real time.

## Features

- Renders a detailed fountain basin and environment using `.obj` models.
- Uses textured surfaces for grass, pebbles, water and other materials.
- Demonstrates a simple particle system for the fountain’s water effects.
- Includes a Windows executable (`Fountain.exe`) built with Visual Studio.
- Modular directory structure (source code, headers, resources, libraries, debug builds).

## Project structure

| Folder | Purpose |
| --- | --- |
| `src` | C++ source files for rendering, input handling and simulation logic |
| `include` | Header files and third‑party includes |
| `lib` | External library binaries required for the project |
| `resource` | Models, textures and other assets used in the scene |
| `Debug` | Temporary build artifacts generated by Visual Studio |

## Requirements

- **Development tools:** Visual Studio 2019 or newer (project files are included).
- **Dependencies:** OpenGL libraries, [FreeImage](https://freeimage.sourceforge.net/) for image loading and any additional libraries in the `lib` directory.
- **Operating system:** Windows (tested with the provided executable).

## Building from source

1. Clone this repository to your local machine.
2. Open `Fountain.sln` in Visual Studio.
3. Ensure the include and library directories (`include` and `lib`) are correctly configured in the project’s properties.
4. Build the solution in either *Debug* or *Release* mode.
5. Run the generated executable from the `Debug` or `Release` folder.

Alternatively, you can compile manually using a C++ compiler and link the required libraries. Make sure to include the header files from `include` and link against the binaries in `lib`.

## Running the demo

If you just want to see the fountain demo in action without compiling:

1. Download or clone this repository.
2. Navigate to the root of the repository.
3. Open the `Fountain.exe` file to launch the demo.
